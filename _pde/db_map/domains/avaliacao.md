# Avaliação / Notas

## Conceitos principais

- Avaliacao: instrumento de avaliação aplicado a uma turma
- Nota: valor atribuído a um aluno em uma avaliação
- Bimestre: período letivo de referência

## Fluxo

Turma → Avaliacao → Nota (por aluno)
