# EFC-6292 — Migração de endpoint da Ficha Individual de notas para estrutura-avaliacao

> **Fonte:** Jira (`gruposalta.atlassian.net`) — somente leitura. Não edite campos sincronizados diretamente aqui.  
> **Status:** Aberta | **Tipo:** Technology | **Prioridade:** Medium | **Última sincronização:** 2026-05-14

---

## 1. Contexto e Motivação

O escopo dos módulos foi repensado e o módulo de `estrutura-pedagogica` será o futuro módulo central do time. Atualmente existe um endpoint no módulo de `notas` que retorna dados da Ficha Individual para o módulo de `documentacao-pedagogica`. É necessária uma atualização nesse endpoint e, como o novo módulo central passa a ser `estrutura-pedagogica`, faz sentido migrar esse endpoint (e seus objetos/serviços relacionados) para lá.

**Epic pai:** [EFC-5972 — Itinerário Formativo](https://gruposalta.atlassian.net/browse/EFC-5972) (Em Progresso)  
**Label:** `Rep:EstruturaPedagogica`

---

## 2. Critérios de Aceitação

Não especificado explicitamente no card. Com base no contexto:

- O endpoint que serve dados da Ficha Individual deve ser removido (ou deprecado) do módulo `notas`.
- Um novo endpoint equivalente deve existir no módulo `estrutura-pedagogica`.
- O módulo `documentacao-pedagogica` (consumidor atual) deve ser atualizado para apontar para o novo endpoint.
- Objetos e serviços relacionados ao endpoint devem ser migrados junto, sem duplicação entre módulos.

---

## 3. Subtarefas

Nenhuma subtarefa.

---

## 4. O Que Precisa Ser Feito

1. Identificar o endpoint atual em `notas` que serve a Ficha Individual.
2. Identificar todos os objetos (DTOs, entidades) e serviços relacionados a esse endpoint.
3. Criar o endpoint equivalente em `estrutura-pedagogica`, reaproveitando ou movendo a lógica.
4. Atualizar o módulo `documentacao-pedagogica` para consumir o novo endpoint.
5. Remover ou deprecar o endpoint antigo em `notas`.

- Módulo `documentacao-pedagogica` — chamadas HTTP / cliente do endpoint da Ficha Individual
