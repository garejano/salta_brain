## 1. Contexto e Motivação

O fluxo de desenvolvimento atual do `estrutura-pedagogica` funciona assim:

- **Backend** roda no Visual Studio e está configurado para servir o frontend a partir da pasta `wwwroot`.
- **Frontend** é buildado via `npm run dev` no terminal, que gera o bundle direto em `wwwroot`.

Esse modelo faz o backend consumir o frontend compilado — mas **não oferece hot reload/live reload**. Qualquer alteração no código Angular exige um novo build e um F5 manual no navegador para ver o resultado.

O objetivo é habilitar o HMR (Hot Module Replacement) do Angular `ng serve`, de modo que alterações em arquivos reflitam em tela sem recarregar a página.

## 2. Critérios de Aceitação

- [x] Desenvolvedor edita um arquivo `.ts` ou `.html` do frontend e a mudança aparece no navegador automaticamente, sem F5.
- [x] O fluxo de desenvolvimento com hot reload está documentado.

## 3. Resultado

### Modos de desenvolvimento disponíveis

| Comando | URL | Backend necessário | Uso |
|---|---|---|---|
| `npm run dev:hot` | `http://localhost:4200` | IIS local rodando | Hot reload apontando para backend local |
| `npm run dev:hot-homolog` | `http://localhost:4200` | Não | Hot reload apontando para APIs de homologação |
| `npm run dev` | `https://localhost/estrutura-pedagogica` | IIS local rodando | Legado: build watch sem hot reload |

### O que foi implementado

1. **CORS no backend** — `Startup.cs` passou a aceitar `http://localhost:4200` como origem permitida
2. **Configuração `hot` no `angular.json`** — `baseHref: "/"` e `fileReplacements` para `environment.hot.ts`
3. **`environment.hot.ts`** — `base: ""` para que o callback do ElevaId vá para a rota correta do Angular
4. **`proxy.conf.json`** — encaminha `/ped` para o IIS local (necessário para autenticação e chamadas backend)
5. **Builder migrado de Webpack → esbuild** — HMR estável e rebuilds ~10x mais rápidos
6. **Modo `dev:hot-homolog`** — proxy para homolog, sem precisar de backend local
7. **Bug corrigido** — script `homolog` usava `--configuration=homolog` (configuração inexistente), corrigido para `homologation-iis`
8. **`build-aws` corrigido** — tinha `--configuration=production` hardcoded que conflitava com o CI
