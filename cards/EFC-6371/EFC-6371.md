# EFC-6371 — Novo componente "side-panel" para exibição de dados ao invés de modal

## 1. Contexto e Motivação

O módulo de Cadastro de Hora-Aula exibirá detalhes de cada registro ao clicar em "Ver detalhes". Para isso, é necessário um componente de painel lateral reutilizável — similar a um modal, mas posicionado na lateral direita da tela com scroll interno. Esta atividade cobre apenas a criação do componente; o conteúdo específico de cada tela será implementado nas atividades correspondentes.

O nome sugerido para o componente é `app-side-panel`.

**Epic pai:** [EFC-6357 — Hora Aula](https://gruposalta.atlassian.net/browse/EFC-6357)  
**Label:** `Rep:EstruturaPedagogica`

---

## 2. Critérios de Aceitação

- **CA-01 — Componente independente e reutilizável:** O componente é criado como standalone e separado do componente que o utiliza. A lógica de abertura, fechamento e layout fica encapsulada no próprio componente.
- **CA-02 — Abertura e fechamento controlados pelo pai:** O componente expõe um `@Input()` para controle de visibilidade e emite um `@Output()` ao ser fechado. O componente pai decide quando abrir e reage ao evento de fechamento.
- **CA-03 — Fechamento por "x" ou overlay:** O painel fecha ao clicar no botão "x" interno ou ao clicar fora do painel (overlay semitransparente).
- **CA-04 — Posicionamento e layout:** O painel ocupa toda a altura lateral direita da tela, com scroll interno quando o conteúdo ultrapassar a altura disponível. Um overlay semitransparente cobre o restante da tela enquanto o painel está aberto.
- **CA-05 — Projeção de conteúdo:** O componente utiliza projeção de conteúdo (`ng-content`) para receber o conteúdo específico de cada uso, sem conhecimento da lógica de negócio de quem o implementa.

## 4. O Que Precisa Ser Feito

Criar o componente `app-side-panel` como standalone no repositório `EstruturaPedagogica` (label `Rep:EstruturaPedagogica`):

- **Localização:** `frontend/src/shared/components/side-panel/`
- **Padrão:** standalone, sem NgModule — seguir o mesmo modelo do `app-modal` existente
- **Interface pública:**
  - `@Input() show: boolean` — controla visibilidade
  - `@Output() closeEvent: EventEmitter` — emite ao fechar
- **Layout CSS:** `position: fixed; right: 0; top: 0; height: 100vh; overflow-y: auto` + overlay escuro semitransparente
- **Fechamento:** ao clicar no botão "x" interno ou no overlay
- **Projeção:** usar `<ng-content>` para o conteúdo — sem lógica de negócio no componente
- Referência visual: drawer sobreposto à listagem, com título, abas internas, seções de campos e botões de ação no rodapé (estrutura implementada pelos consumidores, não pelo `app-side-panel`)

### Após criar o componente — tela de exemplo no módulo de exemplos

Criar uma tela de demonstração do `app-side-panel` dentro do **módulo de exemplos** do frontend. O módulo de exemplos possui um dashboard listando os exemplos disponíveis; a nova tela deve ser registrada nesse dashboard.

A tela de exemplo deve:
- Ter um botão que abre o side-panel
- Projetar conteúdo fictício dentro do painel (ex: campos de detalhe, seção de texto)
- Demonstrar o fechamento pelo "x" e pelo overlay
- Servir como referência viva para outros devs que forem consumir o componente
